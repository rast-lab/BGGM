# Print method for `BGGM` objects

Mainly used to avoid a plethora of different print functions that
overcrowded the documentation in previous versions of **BGGM**.

## Usage

``` r
# S3 method for class 'BGGM'
print(x, ...)
```

## Arguments

- x:

  An object of class `BGGM`

- ...:

  currently ignored
